# Photography Portfolio

Photography portfolio for Neil. Every photograph was taken and edited by Neil. Editing inquiries: paineil.1008@gmail.com.

## Experience and stack

HTML and CSS in the browser, generated by a dependency-free C11 program. No client-side JavaScript, frameworks, backend, or external fonts.

- Four subject collections: Wildlife (33), Landscapes (16), Water & Coast (12), Architecture (3).
- All 64 photographs are mixed across subjects in the default view. Locations are caption/viewer metadata, never browsing groups.
- Native bookmarkable category links, contact-sheet mode, and fullscreen popovers with Escape to close.
- Minimal darkroom theme: charcoal surfaces, neutral typography, a static opening photograph, and a consistent two-column gallery. Reduced-motion preferences are respected.
- Location shown next to each image, in frame notes, and prominently in the enlarged viewer.
- Editing credit, email inquiries, and camera exposure details.

## Build

From the repository root, with a C11 compiler:

```sh
cc -std=c11 -Wall -Wextra -Werror -pedantic tools/gallery.c -o gallery
./gallery data/photos.tsv templates/page.html > index.tmp.html
# Replace the checked-in page only after a successful exit.
mv index.tmp.html index.html
```

Open index.html in a current browser. Popovers and CSS :has() need a modern browser.

## Manifest

`data/photos.tsv` has fourteen nonempty tab-separated columns:

`Title | Subject | Category | Image URL/path | Alt text | Source camera | Region | Shutter | Aperture | ISO | Width | Height | Location | Location precision`

Pipes above illustrate columns; the file uses tabs. Categories are wildlife, landscapes, water, architecture. Region slugs (kenya, alberta, iceland, montenegro, corfu, montserrat) are internal provenance, not UI groups. Precision is confirmed, identified, or regional. Source camera is retained in data but not shown; there is no lens field. Use Not supplied for unknown exposure settings.

Provide positive horizontal dimensions, no tabs/newlines inside fields, and up to 256 entries. Image paths must start with assets/photos/ or https://. Local WebP exports use an 1800-pixel-wide image and an 800-pixel-wide -small.webp companion. Rebuild after changing the template or manifest. Update collection counts if adding/removing photographs.

## Locations

User-supplied destinations are retained. Fourteen photos have more specific visually identified landmark labels, marked identified and accompanied by an explicit viewer/frame-note caveat. These are visual inferences, not GPS confirmations. Other photos retain the confirmed broader region because the exact shooting point or Kenya park could not be established. No precise coordinates are published.

`data/photo-sources.json` maps original filenames, subject categories, locations, precision, and official landmark reference URLs. A reference verifies what/where a landmark is; it does not independently prove the capture location of a user photo. Kenya park reference research did not establish a reliable per-image park assignment.

## Photographs and watermark

64 original horizontal photographs: 44 from the initial collection, 10 Iceland images, six selected Bar/Corfu images, and four Montserrat images. Portrait images, exact duplicates, and weaker or repetitive travel images were excluded.

Every full and responsive WebP contains a subtle lower-right neil's photos watermark rendered into its pixels. Original files remain untouched outside the repository. Derivatives omit EXIF, including GPS. The C generator renders the prepared manifest; it does not extract EXIF, watermark, or compress photos itself.

## Checks and publishing

GitHub Actions compiles with strict warnings and address/undefined-behaviour sanitizers, checks invalid input and HTML escaping, enforces horizontal dimensions, verifies generated HTML is current, and creates a seven-day downloadable artifact. The public repository is connected to Vercel for automatic production deployment from main. The earlier hosted Sites draft is separate.
