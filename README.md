## Build

With a C11 compiler installed, run from the repository root:

```sh
cc -std=c11 -Wall -Wextra -Werror -pedantic tools/gallery.c -o gallery
./gallery data/photos.tsv templates/page.html > index.tmp.html
# Replace the checked-in page only after a successful generator exit.
mv index.tmp.html index.html
```

Open `index.html` in a current browser. Native popovers, CSS `:has()`, and scroll animations need modern browser support. Unsupported scroll animations fall back to static photographs.

## Photo manifest

`data/photos.tsv` has twelve nonempty tab-separated fields per photograph:

`Title | Subject | Category | Image URL/path | Alt text | Source camera | Region | Shutter | Aperture | ISO | Width | Height`

Pipes illustrate columns; the actual separators are tabs. Categories: `birds`, `mammals`, `landscapes`. Regions: `kenya`, `alberta`, `iceland`. Camera is retained as import data and is not displayed. Lens data is not retained. Use `Not supplied` for unknown settings. Up to 256 photographs are supported. Width and height describe the full WebP export and must be positive horizontal dimensions. Image URLs must begin `https://` or `assets/photos/`. Escape tabs/newlines out of field text.

For local WebP images, provide an 1800-pixel-wide version and an 800-pixel-wide `-small.webp` companion. All website images must be horizontal after orientation is applied. Rebuild after changing the manifest or template.

## Original work

54 horizontal original photographs: 44 retained from the first batch, plus 10 new Iceland photos. One vertical Iceland photograph was removed; one exact duplicate was already excluded during initial import. `data/photo-sources.json` maps website filenames to original filenames and regions.

WebP copies are optimized for the website; originals remain untouched outside the repository. Capture metadata was extracted during import where available. Exported images omit EXIF, including GPS. The C generator reads the prepared manifest; it does not extract EXIF or compress photos itself.

## Validation and privacy

GitHub Actions builds C with strict warnings and address/undefined-behaviour sanitizers, checks invalid input and HTML escaping, verifies generated HTML is current, and provides a seven-day downloadable website artifact. No deployment workflow or GitHub Pages configuration is present. This repository stays private; the earlier hosted Sites draft is separate.
